# Honey bees show no olfactory preference for sodium-enriched nectar

Data, analysis code, and experimental materials for a Y-maze behavioral study investigating whether western honey bees (*Apis mellifera*) exhibit an olfactory preference for sodium-enriched artificial nectar.

## Study overview

This study tested whether sodium enrichment alters nectar odor sufficiently to influence honey bee foraging decisions, potentially through the salting-out effect, in which dissolved salts increase the release of volatile compounds into the air.

We tested 102 foraging honey bees in a Y-maze choice assay, presenting them with odor sources containing control artificial nectar (diluted honey) and sodium-enriched artificial nectar at one of two sodium concentrations (35 mM or 3500 mM Na⁺). Bees were assessed for olfactory preferences without direct access to the nectar.

Three behavioral metrics were recorded:

- **Initial choice:** which odor source the bee approached first (sodium-enriched or control)
- **Time:** proportion of time spent in the sodium-enriched arm
- **Visits:** number of visits to the sodium-enriched and control arms

Each metric was analyzed using generalized linear mixed models (GLMMs), with candidate models compared using the corrected Akaike Information Criterion (AICc).

No olfactory preference for sodium-enriched nectar was detected at either concentration.

## Data

Raw data is stored in `data/` as three CSV files that are joined during cleaning:

- `full_trial_data.csv` — trial-level behavioral observations, including initial choice, time, and visits
- `full_collection_data.csv` — bee collection records (location, flower, cage)
- `full_batch_data.csv` — artificial nectar batch records (target/actual sodium concentrations, mixing times)

Processed data is generated by the analysis pipeline and saved to `data/processed/`.

## Analysis pipeline

Run the full pipeline from the project root in R:

```r
source(here::here("R", "main.R"))
```

`main.R` sources the analysis scripts in sequence:

| Script | Purpose | Key outputs |
|---|---|---|
| `01_clean_data.R` | Join raw CSVs and derive analysis variables | `data/processed/trial_data_clean.rds`, `trial_data_clean.csv` |
| `02_fit_models.R` | Fit candidate GLMMs for each behavioral metric and compare models using AICc | `results/model_results.rds` |
| `04_analyze_results.R` | Generate descriptive statistics, model-selection tables, and selected-model estimates | Console output |
| `05_make_plots.R` | Generate Figure 2 (behavioral metrics), Figure S1 (bee collection locations), and Figure S2 (DHARMa diagnostic plots), each as a vector PDF and a 600 dpi PNG | `plots/Figure2_Behavioral_Metrics`, `plots/FigureS1_Collection_Locations`, `plots/FigureS2_DHARMa_Checks` (`.pdf` and `.png`) |

**Model diagnostics:** `03_check_diagnostics.R` is not included in the automated pipeline. It generates DHARMa residual diagnostics for interactive assessment of model fit and can be run separately when needed.
