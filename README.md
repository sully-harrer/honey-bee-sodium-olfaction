# Honey bees show no olfactory preference for sodium-enriched nectar

Data, analysis code, and experimental materials for a Y-maze behavioral study investigating whether western honey bees (*Apis mellifera*) exhibit an olfactory preference for sodium-enriched artificial nectar.

## Study overview

This study tested whether sodium enrichment alters nectar odor sufficiently to influence honey bee foraging decisions, potentially through the salting-out effect, in which dissolved salts increase the release of volatile compounds into the air.

We tested 102 foraging honey bees in a Y-maze choice assay, presenting them with odor sources containing control artificial nectar (diluted honey) and sodium-enriched artificial nectar at one of two sodium concentrations (35 mM or 3500 mM Na⁺). Bees were assessed for olfactory preferences without direct access to the nectar. Two trials were excluded, leaving 100 for analysis.

Three behavioral metrics were recorded:

- **Initial choice:** which odor source the bee approached first (sodium-enriched or control)
- **Time:** proportion of time spent in the sodium-enriched arm
- **Visits:** number of visits to the sodium-enriched and control arms

Each metric was analyzed using generalized linear mixed models (GLMMs), with candidate models compared using the corrected Akaike Information Criterion (AICc).

No olfactory preference for sodium-enriched nectar was detected at either concentration.

## Data

Raw data is stored in `data/` as three CSV files that are joined during cleaning, plus the hive location
shown in Figure S1:

- `full_trial_data.csv` - trial-level behavioral observations, including initial choice, time, and visits
- `full_collection_data.csv` - bee collection records (location, flower, cage)
- `full_batch_data.csv` - artificial nectar batch records (target/actual NaCl, mixing times)
- `hive_location.csv` - coordinates of the known hive near the collection sites

Every column, its units, and how the files link together are described in
[`data/README.md`](data/README.md). Processed data is generated by the pipeline and saved to
`data/processed/`.

## Reproducing the analysis

Requirements:

- R 4.6.1 (the version recorded in `renv.lock`)
- The Arial font installed on the system (used in every figure)
- An internet connection for Figure S1, which downloads Esri satellite tiles. Without one, `main.R`
  stops with an error at Figure S1. Everything else (cleaned data, results, Figures 2 and S2) has already
  been written by then.

From the project root, in R:

```r
renv::restore()        # installs the exact package versions in renv.lock
source("R/main.R")     # runs the whole pipeline
```

Opening `honey-bee-sodium-olfaction.Rproj` (or starting R in the project root) activates renv
automatically.

## Analysis pipeline

`main.R` sources the analysis scripts in sequence:

| Script | Purpose | Key outputs |
|---|---|---|
| `01_clean_data.R` | Check the raw CSVs, join them, and derive analysis variables | `data/processed/trial_data_clean.rds`, `trial_data_clean.csv` |
| `02_fit_models.R` | Fit 8 candidate GLMMs for each behavioral metric and compare them using AICc | `results/model_results.rds` |
| `04_analyze_results.R` | Descriptive statistics, model-selection tables, and model estimates with 95% Wald CIs | Console output, `results/model_selection.md`, `results/estimates.csv` |
| `05_make_plots.R` | Figure 2 (behavioral metrics), Figure S1 (bee collection locations), and Figure S2 (DHARMa diagnostic plots), each as a vector PDF and a 600 dpi PNG | `plots/Figure2_Behavioral_Metrics`, `plots/FigureS1_Collection_Locations`, `plots/FigureS2_DHARMa_Checks` (`.pdf` and `.png`) |

The `.rds` files are not tracked in git. Rerun the pipeline to recreate them.

**Model diagnostics:** `03_check_diagnostics.R` is not included in the automated pipeline. It generates DHARMa residual diagnostics for interactive assessment of model fit and can be run separately when needed. It uses the same random seed as `05_make_plots.R`, so its residuals match Figure S2.
