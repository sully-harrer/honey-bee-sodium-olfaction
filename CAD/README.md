Laser-cut parts for the Y-maze used in this study.

- **Material:** Designed for 1/8" (3.175 mm) thick cast acrylic.
  - `black_acrylic_y_maze.dxf`: maze body (black acrylic)
  - `clear_y_maze_top.dxf`: top panel (clear acrylic)
- **Note:** These are the files I actually used, but they aren't perfect. Some of the joints came out loose or weren't optimal, so you may want to tweak the fits before cutting your own.

If you have questions, or want to use these files and need more detail on what should be changed or how the parts fit together, open an issue or reach me via my GitHub profile (@sully-harrer).
